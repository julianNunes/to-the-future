## 🚦 Como Usar Esta Documentação

### 🆕 **Primeira vez no projeto?**

Comece com **[Início Rápido](01-quick-start.md)** → execute `./start.sh setup` → pronto!

### 🔍 **Precisa entender como funciona?**

Leia **[Arquitetura](02-architecture.md)** → depois **[Ambiente de Desenvolvimento](03-development-environment.md)**

### ⚡ **Precisa de comandos rápidos?**

Consulte **[Comandos Essenciais](04-essential-commands.md)** → ou execute `./start.sh` sem parâmetros

### 🐛 **Algo não está funcionando?**

Vá direto para **[Resolução de Problemas](06-troubleshooting.md)** → ou `./start.sh check`

### 📚 **Quer aprender Laravel?**

Comece com **[Guia Laravel](07-laravel-guide.md)** → documentação completa do framework
